# hm hamzury — website and personal OS

Saved website source, transferred to GitHub on 7 November 2026. This repository is private.

## Contents

- `src/`: the development source. Edit files here, never in `dist/`.
  - `src/*.html`: website pages, photographs, portraits, brand motif (`assets/`) and downloadable PDFs (`downloads/`).
  - `src/os/`: browser-local personal workspace, application tracker, Stationery Forge and encrypted account vault.
  - `src/locations.html`: Abuja and Jos addresses/map links with copy and sharing controls.
  - `src/inline/`: each page's own CSS and JavaScript. Pages load these with `<link ... data-inline>` / `<script src="..." data-inline>`; the build inlines them back into the page, so they are not shipped as separate files.
- `dist/`: the built static website (generated by `npm run build`, deploy this folder).
- `scripts/`: `build.mjs` (src → dist) and `dev.mjs` (local server with live reload).
- `sources/book/`: ASSSS manuscript and PDF generation source. The first edition remains **In review**. `build_book.py` writes the PDF to `src/downloads/`; run `npm run build` afterwards.

## Development

Requires Node.js 18+.

```sh
npm install
npm run dev        # http://localhost:8000, serves src/ and reloads on save
npm run build      # writes dist/ (pages inlined and minified)
npm run preview    # http://localhost:4173, serves the built dist/
npm run format     # Prettier over src/
```

`npm run build:readable` builds without minification, useful for checking output.
The scripts are classic (non-module) scripts sharing globals that inline `onclick="..."` attributes call, so keep them as plain `<script>` files rather than ES modules.

For actual use, serve over HTTPS. The vault requires browser Web Crypto support (`localhost` also counts as secure).

## Storage and privacy

Workspace records live in the user's browser. They are not included in this source repository. Export backups from each workspace module. The account vault uses AES-GCM encryption with a passphrase-derived key and has its own encrypted export/restore controls. Keep passwords, recovery codes, exported vaults, API keys, database files and environment settings outside Git.

The currently hosted preview is owner-private. The `/os/` static route does not itself enforce server authentication. Keep the whole preview private until the public website and private OS are separated or protected with verified server access controls.
